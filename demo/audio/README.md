# Audio provenance

## Original recordings / portfolio placeholders

- `STIM_CARRIER_step4.wav` – author-recorded placeholder for the carrier block.
- `STIM_CONTEXT_step4.wav` – author-recorded placeholder for the sentence-context block.

The demo repeats these two files. The original source ZIP contained seven identical copies of each type (`step1` through `step7`); these **were not seven distinct validated steps** and are not represented as such in this release.

## McDermott Lab headphone screening

The six `antiphase_HC_*.wav` files are credited to the McDermott Lab `HeadphoneCheck` project. See the upstream repository, https://github.com/mcdermottLab/HeadphoneCheck, and the required BSD 2-Clause licence and AUTHORS notice in `../../third_party/`.

## Volume check

- `beep.wav` – newly generated 600 Hz, 0.55-second sine wave (stereo, 44.1 kHz) with a brief fade in/out; not the beep copied from the original source ZIP.

The demo does not save or send response data.
